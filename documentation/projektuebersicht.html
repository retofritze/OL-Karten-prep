Drehtür-Programm · GRG17 Geblergasse

Orientierungslauf-Karten zeichnen automatisiert vorbereiten

Dieses Projekt läuft im Rahmen des Drehtür-Programms des GRG17 Geblergasse.

Ziel des Projektes ist es, die Vorarbeiten vor dem Zeichnen einer Orientierungslauf-Karte (z. B. Importieren von Luftbild und Höhenschichtenmodell) zu automatisieren. Das Ergebnis ist eine Datei, die im Programm Open Orienteering Mapper fertiggezeichnet und dann z. B. in Purple Pen zum Bahnlegen verwendet werden kann.

Schnittstelle

API zwischen Verarbeitung und Darstellung

Lokal umgesetzt · noch nicht online

Website und Kommandozeile nutzen dieselbe Logik. Die Website spricht sie über diese Schnittstelle an. Weil eine Karte zwischen 30 Sekunden und einigen Minuten braucht, arbeitet die API mit Aufträgen. Man schickt einen Auftrag ab, fragt den Fortschritt ab und lädt am Ende das Ergebnis herunter. Aufträge laufen nacheinander. Solange einer läuft, warten die nächsten im Status wartend.

Lokal gestartet (python -m uvicorn api.main:app), zeigt die API unter /docs eine eigene Dokumentation zum Ausprobieren. FastAPI erzeugt sie aus dem Programmcode.

POST /auftraege→GET /auftraege/{id}… bis „fertig“ →GET /auftraege/{id}/ergebnis
Basis-URL: /api/v1 Format: application/json; charset=utf-8 Fehler: { "fehler": "…" } Koordinaten: WGS84 (Grad)
GET/symbolsaetzeSymbolsätze und erlaubte Maßstäbe

Liefert die Symbolsätze aus OpenOrienteering Mapper und die Maßstäbe, für die es sie gibt. Die Website zeigt nach der Wahl des Symbolsatzes nur die passenden Maßstäbe an.

POST/auftraegeNeuen Kartenauftrag anlegen

Anfrage

FeldTypBedeutung
name *stringKartenname, wird Datei- und Ordnername
bbox *number[4]Kartenbereich: West, Süd, Ost, Nord in Grad (WGS84)
massstab *integerz. B. 4000 für 1:4000; muss zum Symbolsatz passen
symbolsatzstringStandard: ISSprOM 2019 bei 1:4000, sonst ISOM 2017-2
aequidistanznumberAbstand der Höhenlinien in m; Standard 2,5 (Sprint) bzw. 5
zaehlkurvenumberAbstand der Zählkurven in m, Vielfaches der Äquidistanz; Standard 5 × Äquidistanz
osmbooleanOpenStreetMap-Objekte (Gebäude, Wege, Zäune …) übernehmen; Standard true

* Pflichtfeld. Der Bereich muss in Österreich liegen und beim gewählten Maßstab auf ein A3-Blatt passen (z. B. 4,2 × 2,97 km bei 1:10 000). Der Name darf nur Buchstaben, Ziffern, _ und - enthalten.
